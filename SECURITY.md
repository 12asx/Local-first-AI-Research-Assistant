# Security policy

ResearchAgent is primarily intended for local use on trusted machines. It is not certified for exposure on a public IP or shared-hosted service.

Please report potential vulnerabilities privately using GitHub's **Report a vulnerability** / private vulnerability reporting feature, if enabled for this repository. Do not publish API keys, private papers, or sensitive logs in public issues.

The maintainers should configure private vulnerability reporting and secret scanning in repository settings. Rotate any exposed key immediately; removing the current file is not sufficient when the key exists in Git history.
