# Contributing to ResearchAgent

Thanks for your interest! Before making a change:

1. Open an issue describing the bug or proposed feature.
2. Create a feature branch and add tests when behavior changes.
3. Run `python -m pytest -q` and check the code style.
4. Submit a pull request explaining how to reproduce and verify the change.

Do not submit unpublished research manuscripts, private PDF files, API keys, saved chat histories, personal information, or logs containing such data. For security vulnerabilities, follow `SECURITY.md` rather than posting an exploit publicly.
